# Engineering Projects

A collection of software, embedded-systems, graphics, GPU-computing, and data-analysis projects.

## Projects
- **3D Chess Game** — C++ / OpenGL chess application with Komodo chess-engine integration.
- **ESP32 ABS Prototype & Wireless Autonomous RC Car** — Embedded systems using BLE, ESP-NOW, Python, sensors, and motor control.
- **Atari Centipede Game** — C++ / SFML arcade game with collision detection, enemies, projectiles, and scoring.
- **CUDA-Accelerated Conway's Game of Life** — C++ / CUDA / SFML cellular automaton accelerated on the GPU.
- **XOR Bitstream Analysis** — Python utility for validating, XORing, and analyzing binary streams.

## Technologies
C/C++, Python, CUDA, OpenGL/GLSL, SFML, ESP32/Arduino, ESP-NOW, BLE, CMake, multithreading, embedded sensors, and GPU programming.

## Focus
These projects emphasize system integration, debugging, real-time software, embedded communications, graphics, and performance-oriented programming.
